# MiniLoop Baby Gear Rentals — GitHub Pages website

A responsive, single-page website for MiniLoop, using the supplied logo and its forest-green / soft-sage visual identity.

## Publish with GitHub Pages

1. Sign in to GitHub and create a **new public repository** (for example, `miniloop-website`).
2. Upload all files and folders from this project. Keep `index.html` at the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Wait for GitHub to publish the site. Your URL will look like `https://YOUR-USERNAME.github.io/miniloop-website/`.
